## How to write a real one

Create a file at `content/thoughts/your-slug.mdx` with frontmatter:

```yaml
---
title: The title of the post
summary: One or two sentences, shown on the index page.
date: 2026-09-02
track: tech # or: theology
---
```

Then write the body in Markdown below it. Drop the `draft` field entirely, or
set it to `false`, when it is ready to publish.

Standard Markdown works, plus GitHub-flavoured extras — tables, strikethrough,
task lists. Headings automatically get anchor links.
