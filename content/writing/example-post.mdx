## Writing a real one

Create `content/writing/your-slug.mdx`:

```yaml
---
title: The title
summary: One or two sentences, used on index pages and in the RSS feed.
date: 2026-09-02
track: code      # code | gaming | theology | devlog
project: shepherds-we-shall-be   # optional
---
```

`track` decides where the post surfaces. Everything appears on `/writing`;
`gaming` posts also appear on `/gaming`, and `theology` posts on `/orthodoxy`.

Setting `project` to a project's slug attaches the post to that project, so it
shows on that project's page too. That is how devlog entries work — `track:
devlog` plus `project: shepherds-we-shall-be`.
