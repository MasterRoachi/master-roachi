Eight exercises worked through The Odin Project's foundations track, from
HTML/CSS fundamentals up to DOM manipulation and event handling.

The repository is its own hub — the index page links every exercise, so the
whole collection is browsable in one place rather than scattered across
separate repos.

## What's in there

- Admin dashboard layouts, built to practise CSS Grid and Flexbox
- An etch-a-sketch style drawing grid, generated and re-generated from the DOM
- A themed Rock-Paper-Scissors game with score state and result rendering
- Assorted smaller layout and scripting exercises from the same track

## Why it's here

It is foundations work and it is presented as foundations work. The interesting
part is not any single exercise — it is the progression across all eight, from
static markup to scripts that build and tear down the DOM at runtime.
