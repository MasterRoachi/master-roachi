Eight exercises from The Odin Project's Foundations track, kept in one
repository rather than scattered across eight of them. Every one is deployed,
so they can be used rather than just read.

## What the progression actually shows

The interesting part isn't any single exercise. It's the line they draw.

<Split src="/projects/odin-projects-a.webp" side="left">

The early ones are layout: the **Admin Dashboard** is CSS Grid pushed until it
stops being comfortable, and the **Questicles Landing Page** is the same
exercise for Flexbox. Nothing moves. The page is what you wrote.

</Split>

Then the DOM starts doing the work. **Etch-A-Sketch** builds its own grid at
runtime and rebuilds it whenever the size changes, which is the first point
where the markup you write and the markup that exists stop being the same
thing. **Quartz, Parchment, Shears** adds state that outlives a click.

**Coolculator** is where it gets awkward. A calculator looks trivial until you
try to chain operations, and then the edge cases outnumber the happy path —
what a second operator does mid-expression, what the display shows versus what
the machine is holding.

The last three separate state from rendering properly. **Tic-Tac-Toe** keeps
the board in JavaScript and draws it, rather than reading the page back to
find out whose turn it is. **The Ark** does the same for a collection of
objects. **KOI** generates its entire page from modules with no static markup
at all.

That is the whole arc of Foundations: from writing what the browser shows, to
writing the thing that decides what the browser shows.
