This site. Built with the Next.js App Router and exported as a fully static
site, so there is no server to run and nothing to keep patched.

## How it's put together

Writing, project pages, and devlog entries are all MDX files on disk, read at
build time through one small content layer. Adding a post means adding a file —
there is no CMS and no database.

Every page is rendered at build time and served as static HTML — there is no
server deciding anything at request time. The navigation is the only piece
that runs as a client component.

That said, the framework brings its own runtime along: around 175 KB of
compressed JavaScript on the homepage, mostly React and the client router.
Honest number rather than a claim of zero.

## Design

The recurring diamond sigil, the grain, and the layered gold and teal glows all
carry over from the original design pass. Gold marks work that is real and
shipped; teal marks anything still ahead of it. That rule holds across the
whole site.
